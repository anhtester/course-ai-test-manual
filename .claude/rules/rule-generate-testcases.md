# Đây là quy định khi generate Test Case Manual từ mô tả chức năng

## Yêu cầu:
- Bao gồm Happy path, Negative case, Edge case (tối thiểu 30% là Negative/Edge case).
- Mỗi Test Case có: Tiền điều kiện, Các bước thực hiện, Dữ liệu test, Kết quả mong đợi, Độ ưu tiên (High/Medium/Low), Is Automation (Yes/No).
- Mã Test Case theo định dạng: TC_<MODULE>_<số thứ tự 3 chữ số>. Ví dụ: TC_LOGIN_001, TC_LOGIN_002, TC_LOGIN_003, ...
- Trình bày dạng bảng Markdown. Nếu người dùng muốn xuất ra file Excel, hãy dùng định dạng bảng Markdown để dễ dàng copy sang Excel.
- Viết toàn bộ bằng tiếng Việt.
