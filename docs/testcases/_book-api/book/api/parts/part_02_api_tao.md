> Mỗi TC tạo sách dùng **tên riêng** `Auto BookAPI <tag> <T>` (né ràng buộc trùng tên — F-29) và **danh mục riêng** `auto_bookapi_cat_<tag>_<T>`. `POST /api/book` **không trả `id`** — tra bằng `GET /api/book?search={"name":{"equals":"<tên>"}}`. Mỗi tên danh mục **mới** sinh ra một **danh mục thật** (REQ-52) → teardown xoá sách **trước**, rồi `DELETE /api/category-book/{name}` — chỉ tên chứa `<T>` (`RISK-BK-BOOK-07`). Sách tạo ra ngoài dự kiến (TC `@KnownBug` cho phép tạo) **phải dọn**.
>
> Trạng thái thành công của `POST` ghi **2xx**: thực tế `200`, spec khai `201` — kiểm riêng ở `TC_102`.
