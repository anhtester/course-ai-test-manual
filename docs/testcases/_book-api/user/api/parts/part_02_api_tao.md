> Mỗi TC tạo người dùng dùng **email riêng** `auto_userapi_<T>_<tag>@auto.test` (`<tag>` ghi ở cột Test Data) để không đụng nhau và truy vết được. Người dùng tạo ra được đưa vào danh sách dọn ở [index](../../TEST_CASES_USER_SUMMARY.md) — `POST /api/user` **không trả `id`**, tra lại bằng `GET /api/user?search=<email>`.
