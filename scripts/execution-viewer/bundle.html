Thông tin lần chạy

Kéo thả file/thư mục report vào đây Hoặc bấm + Import thư mục / + Import file .md ở góc trên — 2 nút đó vẫn còn sau khi đã nạp dữ liệu, bấm thêm được bất cứ lúc nào Nhận docs/executions/<module>/run_*/execution_report.md và retest_*/retest_report.md
Nạp nhiều file cùng lúc để gộp số liệu và so sánh giữa các lần chạy — muốn so sánh nhiều lần chạy thì nạp nhiều thư mục run_*, mỗi thư mục 1 lần chạy.
Kéo thả thì chọn được nhiều thư mục cùng lúc (Ctrl+chọn trong Explorer rồi kéo cả cụm vào); bấm + Import thư mục thì hộp thoại hệ điều hành chỉ cho chọn 1 thư mục mỗi lần — muốn nạp thêm thư mục run_* khác thì bấm nút đó lại, dữ liệu cộng dồn chứ không ghi đè. Nạp nguyên thư mục run_* là có luôn cả report lẫn ảnh evidence — bấm vào ảnh trong ô chi tiết là hiện ngay giữa màn hình.
Toàn bộ xử lý chạy trong trình duyệt — không gửi dữ liệu đi đâu.
