Thông tin hệ thống

Kéo thả file/thư mục bug vào đây Hoặc bấm + Import thư mục / + Import file .md ở góc trên — 2 nút đó vẫn còn sau khi đã nạp dữ liệu, bấm thêm được bất cứ lúc nào Nhận docs/bugs/<module>/BUG_*.md — mỗi file là 1 bug, và/hoặc docs/bugs/README.md (danh mục, cho cái nhìn tổng quan khi chưa nạp từng file chi tiết)
Nạp nhiều file cùng lúc để gộp từ nhiều module.
Bug không có thư mục ảnh riêng — ảnh nằm ở docs/executions/<module>/run_*/evidence/ của lần chạy sinh ra bug đó. Nạp thêm thư mục đó (khớp ảnh theo tên file, không theo đường dẫn, nên nạp từ đâu cũng được) để xem được luôn ảnh evidence — bấm vào ảnh trong ô chi tiết là hiện ngay giữa màn hình.
Kéo thả thì chọn được nhiều thư mục cùng lúc (Ctrl+chọn trong Explorer rồi kéo cả cụm vào); bấm + Import thư mục thì hộp thoại hệ điều hành chỉ cho chọn 1 thư mục mỗi lần — cần cả docs/bugs/ lẫn docs/executions/ thì bấm nút đó 2 lần, dữ liệu cộng dồn chứ không ghi đè.
Toàn bộ xử lý chạy trong trình duyệt — không gửi dữ liệu đi đâu.
